About Sentinel SOC

Educational URL screening and monitoring interface.

MISSION

Offline URL risk screening

Sentinel validates an HTTP or HTTPS address, extracts URL features, and passes them to a locally saved Random Forest model when compatible artifacts are available. It never visits submitted URLs or downloads page content.

MODEL SCOPE

Offline URL lexical model

The Random Forest is trained from the dataset's labeled raw URLs using the same 13 URL-text features calculated at scan time. The dataset's other precomputed page-content and external-service signals are excluded because they cannot be calculated without visiting sites. The app does not visit submitted URLs.

INTERPRETATION

Estimates need human review

Model probabilities and risk categories are presentation estimates, not guarantees or calibrated security scores. A legitimate classification does not prove a website is safe. Verify unexpected links through a trusted route.

LOCAL STORAGE

Scan records stay in SQLite

Successful prediction results are stored locally in database/security.db. Submitted URLs are displayed with HTML escaping and stored using parameterized SQL.
